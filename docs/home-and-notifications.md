# Главная страница и сигнал о новых задачах

## Новые задачи и колокольчик

Задача считается **новой**, пока назначенный на неё пользователь её не открыл. Новой она бывает, только если её
назначил кто-то другой: задачи, созданные самим пользователем, и назначения самому себе новыми не считаются. Завершённые
и отменённые задачи в «новые» не попадают.

Иконка уведомлений в верхней панели показывает три состояния:

| Состояние | Значок |
| --- | --- |
| есть новые, не просмотренные задачи | большой красный круг с восклицательным знаком |
| новых задач нет, но есть другие непрочитанные уведомления | маленький красный кружок |
| ничего нового | без значка |

При наведении под заголовком «Уведомления» показываются новые задачи, ниже — остальные непрочитанные уведомления
(уведомление о самом назначении не дублируется). Если новых задач нет, написано «У вас нет новых задач»; кнопка
«Отметить прочитанным» внизу заблокирована, пока нечего отмечать. Кнопка отмечает прочитанными все уведомления и
считает все новые задачи просмотренными.

Задача перестаёт быть новой, когда исполнитель открывает её (страница задачи или боковая панель просмотра), либо после
«Отметить прочитанным». В боковом меню у пункта «Уведомления» восклицательный знак тоже показывается только при новых
задачах.

Технически: поле `IssueAssignee.seen_at` (миграция `0140_issueassignee_seen_at`; все уже существующие назначения
помечаются просмотренными, новыми считаются только назначения после обновления). API: `new_tasks` и `new_tasks_count` в
`GET /api/workspaces/<slug>/users/notifications/unread/`, `POST /api/workspaces/<slug>/current-tasks/seen/` (с
`issue_ids` или без них).

## Блок «Текущие задачи» на главной

Находится между «Быстрыми ссылками» и «Недавними». Показывает открытые задачи, назначенные пользователю, в проектах,
которые ему доступны. Порядок:

1. **Сверху всегда новые задачи**: назначены, но не открыты (с пометкой «Новая»), сначала самые свежие назначения.
2. Остальные — по критериям пользователя. По умолчанию: **готовность** (в работе → к выполнению → бэклог →
   завершённые), затем **приоритет** (срочный → низкий). При равенстве выше недавно обновлённая задача.

Кнопка «Порядок» открывает настройки: критерии (готовность, приоритет, срок, обновление, проект), их очередность
и направление, показ завершённых задач и сколько задач показывать до «Показать все». Настройки хранятся для каждого
пользователя и пространства (`WorkspaceHomePreference.config` виджета `current_tasks`). Задачи без срока при
сортировке по сроку всегда в конце.

API: `GET /api/workspaces/<slug>/current-tasks/[?include_completed=1]`. Блок можно скрыть и переставить в «Настройках
виджетов» главной. Недостающие виджеты создаются при первом открытии главной: у существующих пользователей блок появляется
между ссылками и недавними.

## «Недавние»

Список показывает только то, в чём пользователь участвует: проекты, где он состоит; задачи, которые он создал, на
которые назначен, за которыми следит или которые комментировал; страницы, которыми он владеет или которые создал.
Просто открытые чужие объекты не показываются, даже если у администратора есть доступ ко всем проектам. Сортировка — по
времени последнего открытия.
